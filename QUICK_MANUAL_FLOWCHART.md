# 🚀 5-Minute Manual Flowchart Creation (Works Every Time!)

## 📋 Step-by-Step Instructions

### Step 1: Open Draw.io and Start Fresh (30 seconds)
1. Go to **[app.diagrams.net](https://app.diagrams.net)**
2. Click **"Create New Diagram"**
3. Choose **"Blank Diagram"** → Click **"Create"**
4. You now have an empty white canvas

### Step 2: Add Your First Shape - Start (1 minute)
1. **Look at the left panel** (shape library)
2. **Find "Basic Shapes"** section
3. **Drag the "Ellipse"** onto the canvas (anywhere is fine)
4. **Double-click the ellipse** to edit text
5. **Type:** `🏁 User Visits Website`
6. **Press Enter** to save the text

### Step 3: Make It Blue (30 seconds)
1. **Click the ellipse** once to select it
2. **Right-click** → **"Format"**
3. **Click the "Fill" tab**
4. **Choose light blue color** (or type: `#dae8fc`)
5. **Click "Apply"**

### Step 4: Add Homepage Box (1 minute)
1. **From left panel**, drag **"Rectangle"** below the ellipse
2. **Double-click** to edit text: `🏠 Homepage Display`
3. **Right-click** → **Format** → **Fill** → **Light green** (`#d5e8d4`)

### Step 5: Add Decision Diamond (1 minute)
1. **Drag "Diamond"** from left panel below the rectangle
2. **Double-click** to edit: `🔍 Browse Products?`
3. **Format** → **Fill** → **Light yellow** (`#fff2cc`)

### Step 6: Add More Rectangles (2 minutes)
**Add these rectangles one by one:**

**Rectangle 1:** (to the left of diamond)
- Text: `📦 Product Catalog`
- Color: Light green

**Rectangle 2:** (below catalog)
- Text: `📱 Product Detail`
- Color: Light green

**Rectangle 3:** (below product detail)
- Text: `🛒 Add to Cart`
- Color: Light green

**Rectangle 4:** (below cart)
- Text: `💳 Checkout`
- Color: Light orange (`#ffe6cc`)

**Ellipse 2:** (below checkout)
- Text: `🎉 Order Complete`
- Color: Success green (`#d4edda`)

### Step 7: Connect Everything (1 minute)
1. **Click the "Connector" tool** in the toolbar (looks like an arrow)
2. **Connect shapes in this order:**
   - Click start ellipse → Click homepage
   - Click homepage → Click decision diamond
   - Click diamond → Click catalog
   - Click catalog → Click product detail
   - Click product detail → Click cart
   - Click cart → Click checkout
   - Click checkout → Click complete

### Step 8: Final Touches (30 seconds)
1. **Double-click the arrow** from diamond to catalog
2. **Type:** `Yes`
3. **Add more labels** if needed (Login → No, Cart → Yes, etc.)

## 🔧 If You Get Stuck

### Can't Find Shapes?
- **Look for "Basic Shapes"** in left panel
- **Try scrolling down** in the shape library
- **Use search box** at top of left panel

### Shapes Won't Connect?
1. **Make sure connector tool is active** (arrow icon in toolbar)
2. **Click center of first shape**
3. **Click center of second shape**
4. **Arrow appears automatically**

### Want to Move Shapes?
1. **Click the selection tool** (arrow pointing up-left in toolbar)
2. **Click and drag shapes** to reposition
3. **Arrows will follow** automatically

### Need to Change Colors?
1. **Select shape** (click once)
2. **Right-click** → **Format**
3. **Fill tab** → Choose new color
4. **Apply**
