# 🔧 Draw.io Blank Page Fix - Immediate Solutions

## 🚨 Quick Fixes (Try These First!)

### Fix 1: Zoom and Fit (30 seconds)
After importing, if the page looks blank:

1. **Press Ctrl + A** (Select All) - you might see shapes highlighted even if not visible
2. **Click "Fit to Window"** button in toolbar (or Ctrl + Shift + H)
3. **Try zooming out** with mouse wheel or Ctrl + minus
4. **Look for shapes** - they might be positioned off-screen

### Fix 2: Reset View (15 seconds)
1. **View menu** → **Reset View**
2. **View menu** → **Fit Page**
3. **Try Ctrl + 0** (zero) to reset zoom to 100%

### Fix 3: Check if Shapes Exist (10 seconds)
1. **Right-click on canvas** → **Select All** (Ctrl + A)
2. If shapes are there but invisible, you'll see selection boxes
3. **Right-click** → **Arrange** → **To Front**
