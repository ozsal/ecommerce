# 📊 Simple Draw.io Flowchart Guide (No Import Required)

## 🚀 5-Minute Flowchart Creation

### Step 1: Open Draw.io (30 seconds)
1. Go to **[app.diagrams.net](https://app.diagrams.net)**
2. Click **"Create New Diagram"**
3. Select **"Basic Flowchart"** template
4. Click **"Create"**

### Step 2: Clear Template (15 seconds)
1. Select all existing shapes (Ctrl+A)
2. Press Delete to clear the template
3. You now have a blank canvas

### Step 3: Add Your Shapes (3 minutes)

#### 📍 **Shape 1: Start (Oval)**
- **From left panel**: Drag **"Ellipse"** to canvas
- **Double-click** to edit text: `🏁 User Visits Website`
- **Right-click** → Format → Fill: Light Blue `#dae8fc`

#### 📍 **Shape 2: Homepage (Rectangle)**
- **Drag "Rectangle"** below the oval
- **Text**: `🏠 Homepage Display`
- **Color**: Light Green `#d5e8d4`

#### 📍 **Shape 3: Decision (Diamond)**
- **Drag "Diamond"** below the rectangle
- **Text**: `🔍 Browse Products?`
- **Color**: Light Yellow `#fff2cc`

#### 📍 **Shape 4: Product Catalog (Rectangle)**
- **Drag "Rectangle"** to the left of diamond
- **Text**: `📦 Product Catalog`
- **Color**: Light Green `#d5e8d4`

#### 📍 **Shape 5: Product Detail (Rectangle)**
- **Drag "Rectangle"** below catalog
- **Text**: `📱 Product Detail`
- **Color**: Light Green `#d5e8d4`

#### 📍 **Shape 6: Login Check (Diamond)**
- **Drag "Diamond"** below product detail
- **Text**: `🔐 User Logged In?`
- **Color**: Light Yellow `#fff2cc`

#### 📍 **Shape 7: Login Page (Rectangle)**
- **Drag "Rectangle"** to the right of login diamond
- **Text**: `🚪 Login Required`
- **Color**: Light Red `#f8cecc`

#### 📍 **Shape 8: Add to Cart (Rectangle)**
- **Drag "Rectangle"** below login diamond
- **Text**: `🛒 Add to Cart`
- **Color**: Light Green `#d5e8d4`

#### 📍 **Shape 9: Checkout (Rectangle)**
- **Drag "Rectangle"** below cart
- **Text**: `💳 Proceed to Checkout`
- **Color**: Light Orange `#ffe6cc`

#### 📍 **Shape 10: Complete (Oval)**
- **Drag "Ellipse"** below checkout
- **Text**: `🎉 Order Complete`
- **Color**: Success Green `#d4edda`

### Step 4: Connect Shapes (1 minute)
1. **Click the "Connector" tool** in toolbar (arrow icon)
2. **Click first shape**, then **click second shape** to connect
3. **Connect in this order**:
   - Start Oval → Homepage
   - Homepage → Browse Decision
   - Browse Decision → Product Catalog (label: "Yes")
   - Product Catalog → Product Detail
   - Product Detail → Login Check
   - Login Check → Login Page (label: "No")
   - Login Check → Add to Cart (label: "Yes")
   - Add to Cart → Checkout
   - Checkout → Complete

### Step 5: Add Arrow Labels (30 seconds)
1. **Double-click any arrow** to add text
2. **Add these labels**:
   - Browse → Catalog: "Yes"
   - Login Check → Login: "No"
   - Login Check → Cart: "Yes"

## 🔧 If You Get Stuck

### Can't Find Shapes?
- **Look in left panel** under "General" or "Basic Shapes"
- **Search box**: Type "ellipse", "rectangle", or "diamond"

### Can't Change Colors?
1. **Select the shape** (click once)
2. **Right-click** → "Format"
3. **Fill tab** → Choose color
4. **Apply**

### Arrows Won't Connect?
1. **Make sure Connector tool is selected** (arrow in toolbar)
2. **Click exact center** of first shape
3. **Click exact center** of second shape
4. **Arrow should appear automatically**

### Text Too Small?
1. **Double-click shape** to edit text
2. **Select all text** (Ctrl+A)
3. **Use font size buttons** in toolbar to increase

## 🚀 Pro Tips

### ✅ **Alignment**
- Select multiple shapes → Right-click → Arrange → Align
- Use **Align Left**, **Align Center**, **Distribute Vertically**

### ✅ **Spacing**
- Drag shapes to position them
- **Hold Shift** while dragging to keep straight lines

### ✅ **Copying Shapes**
- **Select shape** → Ctrl+C → Ctrl+V
- **Maintains same formatting**

### ✅ **Undo Mistakes**
- **Ctrl+Z** to undo
- **Ctrl+Y** to redo

## 💾 Saving Your Work

### Save to Computer:
1. **File** → **Export as** → **PNG** (for images)
2. **File** → **Download** → **XML** (to edit later)

### Save to Cloud:
1. **File** → **Save as** → Choose Google Drive, OneDrive, etc.
2. **Login** to your account
3. **Name your file** and save
